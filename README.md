# WooCommerce Wallet & Rewards Pro

افزونه‌ای برای افزودن کیف پول و سیستم امتیاز وفاداری به ووکامرس:

- شارژ کیف پول از صفحه حساب کاربری و افزودن مبلغ به سبد خرید.
- پرداخت کامل سفارش با موجودی کیف پول (در صورت کافی بودن موجودی).
- دریافت امتیاز به ازای هر سفارش تکمیل‌شده و امکان تبدیل امتیاز به موجودی کیف پول.
- تنظیمات مدیریتی برای حداقل شارژ، نرخ امتیاز و ارزش امتیاز.

## نحوه استفاده
1. افزونه را در پوشه `wp-content/plugins` قرار دهید و فعال کنید.
2. از منوی **ووکامرس ← تنظیمات ← کیف پول و امتیاز** مقادیر حداقل شارژ، درصد امتیاز و ارزش امتیاز را مشخص کنید.
3. مشتریان از مسیر **حساب کاربری ← کیف پول من** می‌توانند کیف پول را شارژ یا امتیاز را به موجودی تبدیل کنند.
4. در صورت فعال بودن درگاه، «پرداخت از کیف پول» در مرحله پرداخت نمایش داده می‌شود.
